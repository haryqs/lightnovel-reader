# 文档地图

> 项目文档的单一导航入口。AI 接手先读根目录 `AGENTS.md`（= `CLAUDE.md`）。
> 文档分三类：**持久记忆**（随开发更新）、**当前项目**（决策/审阅/发布）、**设计蓝图**（长期方案，少改）。

## 持久记忆 — `dev-memory/`（随每轮开发维护）

| 文件 | 作用 |
|---|---|
| `PROJECT_MEMORY.md` | 项目定位、不可变约束、当前阶段、架构纪律（**第一入口**） |
| `DEVELOPMENT_OUTLINE.md` | v0.3 → v1.0 开发大纲（方向与阶段边界） |
| `NEXT_ACTIONS.md` | 下一步任务队列（P0/P1/…） |
| `DEV_LOG.md` | 开发日志，按时间追加（历史记录） |
| `DECISIONS.md` | 决策日志，记录取舍与理由 |
| `工程约定与陷阱.md` | 代码/协作约定 + “会再踩”的工程陷阱 |
| `SESSION_TEMPLATE.md` | 开工/收工模板 |
| `TOOLING_BACKLOG.md` | 待评估的工具/技能候选 |
| `README.md` | 记忆系统说明 |

## 代码权威优先于文档

协议以 `src/platform/protocol.ts` + reading-core serde 为准；插件契约以 `plugin-sdk/` 为准；
文档描述语义与演进规则，两者冲突时同步修订，不允许单边漂移。
