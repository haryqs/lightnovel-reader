- TypeScript 阅读引擎。
- EPUB 解析与 HTML 清洗。
- 虚拟分页、单页/双页、三主题、字号/版式调节。
- 目录导航。
- 阅读进度持久化。
- 高亮/批注/书签与 Markdown 导出。
- SQLite 本地书库。
- SHA-256 对象仓库去重。
- Calibre 作为导入来源。
- 单本/多本 EPUB 直接导入书库。
- 插件 SDK 契约草案。
- 项目记忆与开发流程工具。

当前最重要的事实：**v0.3 本地书库闭环已完成并经自动冒烟（smoke:tauri/p0/p1）验证，
v0.3.1 加固（迁移框架/解析缓存/安全清洗）+ 安装器已就绪，仅差合并 PR #1 + 一次原生选择器人工点验即可发版。**

## 开发原则

1. **本地体验先于在线资源**
   没有稳定阅读、书库、标注，在线资源越多越会放大混乱。

2. **书库模型先简后繁**
   当前 `books` 单表可继续服务 v0.3。`series/work/volume/edition/asset` 的完整模型等真实需求出现后再迁移。

3. **协议自由期要快，但要守纪律**
   v0.5 之前可以改桥接协议；每次改动必须同步 TS、Rust、文档。

4. **功能必须可验证**
   每个阶段都要有明确验收标准。不能靠“看起来实现了”结束。

5. **合规进入能力层**
   在线资源和插件必须有授权状态、风险等级、能力限制，不靠口头声明。

## v0.3：本地书库闭环

目标：用户可以长期把 EPUB 放进自有书库，而不是只临时打开文件。

### 范围

- 单本/多本 EPUB 导入。
- Calibre 批量导入。
- 去重。
- 书架列表。
- 搜索。
- 最近阅读排序。
- 按书库 id 打开。
- 封面提取。
- series / series_index 元数据。
- 基础错误报告。

### 验收标准

- `npm.cmd run build` 通过。
- `cargo test --workspace` 通过。
- 实机可导入单本 EPUB。
- 实机可导入 Calibre 来源。
- 重复导入不会复制文件。
- 搜索中文标题/作者可命中。
- 从书库打开后，最近阅读时间更新。
- 关闭重开后能恢复阅读位置。

### 推荐实现顺序

1. 补完实机冒烟测试。
2. 提交当前 v0.3 本地书库基线。
3. 根据实机冒烟结果修复封面 URL、文件权限或导入反馈细节。
4. 文档更新与 v0.3 标记。

## v0.4：标注与知识导出增强

目标：让阅读器成为可靠的轻量知识工具。

### 范围

- 跨元素选区高亮。
- 批注编辑体验优化。
- JSON 导出。
- Markdown 导出模板优化。
- text hash fallback 定位增强。
- 标注列表筛选。

### 验收标准

- 高亮跨段落时不静默失败。
- 改字号/版式后，常见标注仍能重定位。
- Markdown 导出可直接进入 Obsidian。
- JSON 导出能完整还原标注数据。

## v0.5：在线元数据与合法入口

目标：开始把“资源发现”接进来，但只做元数据和合法入口。

### 范围

- 粘贴链接识别。
- 官方页面记录。
- 购买/借阅/免费阅读入口。
- 来源授权状态字段。
- source 表 v1。
- 结构化错误码评估。
- 桥接协议冻结前审计。

### 不做

- 不抓受保护正文。
- 不内置盗版源。
- 不绕过登录/付费/DRM。

### 验收标准

- 每条在线来源都有 `rights_status` / `risk_level`。
- 未确认授权来源只能保存链接与元数据。
- 文档和 UI 都能区分“可下载”“只跳转”“只元数据”。

## v0.6：OPDS

目标：接入标准电子书目录，优先服务公共版权和开放授权资源。

### 范围

- OPDS 1.x 订阅。
- OPDS 2.0 初步支持。
- 目录浏览。
- 搜索。
- 开放授权 EPUB 下载入库。
- 授权状态映射。

### 验收标准

- 可添加 OPDS 源。
- 可浏览目录并导入开放授权 EPUB。
- 未授权下载链接不会被自动缓存正文。

## v0.7：插件运行时

目标：实现用户可扩展的 source adapter，但保持安全边界。

### 范围

- QuickJS 桌面运行时。
- `plugin-sdk` manifest 校验。
- `host.http` 域名白名单。
- `host.html` 解析能力。
- `host.kv` 私有存储。
- 官方白名单示例源。

### 验收标准

- 插件不能访问文件系统。
- 插件不能访问未声明域名。
- 插件安装时显示权限与合规信息。
- 官方示例源可搜索、取书目、取章节。

## v0.8：Android

目标：验证“薄壳 + 同一套 engine/core”的移动端路线。

### 范围

- Tauri mobile 优先。
- 若不稳定，手写 Kotlin WebView 壳兜底。
- 文件导入。
- 书库路径与 app data。
- 基本手势。

### 验收标准

- Android 真机可导入 EPUB。
- 阅读、翻页、进度、标注可用。
- 与桌面共享核心数据模型。

## v0.9：iOS

目标：验证 iOS 壳与 JavaScriptCore 插件运行路线。

### 范围

- WKWebView 壳。
- 文件导入。
- app sandbox 书库。
- JavaScriptCore 插件运行时试验。
- App Store 2.5.2 风险验证。

### 验收标准

- iOS 真机可阅读本地 EPUB。
- 插件运行时不违反“下载代码执行”边界。
- 能说明上架路径和侧载路径的差异。

## v1.0：桌面稳定版

目标：让桌面版成为可长期使用的软件，而不是技术样机。

### 范围

- Windows / Linux / macOS 打包。
- 书库迁移策略。
- 协议 1.0 冻结。
- 基础崩溃/错误报告。
- 使用文档。
- AGPL 授权文件。

### 验收标准

- 三大桌面平台可安装运行。
- 用户可以导入书库、长期阅读、导出标注。
- 重要数据可备份和迁移。
- 协议变更规则清晰。

## 风险清单

| 风险 | 应对 |
|---|---|
| 在线资源诱惑导致路线跑偏 | v0.5 前不做正文抓取，只做本地书库 |
| 书库 schema 过早复杂化 | v0.3 继续单表，后续迁移 |
| 标注定位不稳定 | v0.4 加 text hash fallback |
| 多端分散精力 | 桌面先稳定，移动按 v0.8/v0.9 |
| 插件生态变成侵权源生态 | manifest 权限、合规字段、官方白名单 |
