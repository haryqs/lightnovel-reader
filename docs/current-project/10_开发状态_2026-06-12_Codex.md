## 当前结论

v0.3 本地书库已经从“接线闭环”推进到“基本可用，待桌面实机确认”的状态。

已经完成：

- 单本/多本 EPUB 可通过文件选择器导入自有书库。
- Calibre 继续作为导入来源，底层走同一套本地书库入库路径。
- EPUB 入库时按内容哈希去重，写入 `library/objects/<bookId>.epub`。
- OPF 封面图可提取到 `library/covers/<bookId>.<ext>`，并回填 `books.cover_path`。
- OPF 元数据可提取 `language`、`description`、`series`、`series_index`。
- `series/series_index` 兼容 Calibre `calibre:series` 和 EPUB 3 `property` 写法。
- 书架卡片展示封面、作者、系列、卷序、语言、文件大小、最近阅读状态。
- 批量导入会汇总新增、重复、失败数量；失败条目可展开查看。
- `BookInfo.metadata` 与 `LibraryBook` 的 TS/Rust/协议文档字段已同步。
- Tauri asset protocol 已启用，并将访问 scope 限定在 `$APPDATA/**`，用于加载书库封面文件。
