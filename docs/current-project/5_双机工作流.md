# 双机开发工作流

寝室电脑与实验室电脑通过 GitHub 同步，仓库地址：
https://github.com/haryqs/cooperative-plan

## 日常流程

### 开始工作前（拉取最新内容）

```bash
git pull
```

### 结束工作后（推送到云端）

```bash
git add .
git commit -m "简短描述今天做了什么"
git push
```

## 新电脑初始化（只需做一次）

```bash
git clone https://github.com/haryqs/cooperative-plan.git
cd cooperative-plan
```

## 注意事项

- 每次开工前务必先 `git pull`，避免与另一台电脑的修改产生冲突
- 如果两台电脑同时修改了同一个文件，需要手动解决冲突后再提交
- commit 信息尽量写清楚做了什么，方便日后回溯
