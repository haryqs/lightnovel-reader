# 阅读器项目总览

## 这是什么

**护眼三格式阅读器** —— 一款基于 Tauri v2 的跨平台桌面 epub 阅读器，主打轻量、护眼、标注导出。

## 为谁做

- 学术/理论阅读者（马列原著、政治经济学、历史文献）
- 用 Calibre 管理大量 epub 的用户
- 需要标注导出到 Obsidian 的知识工作者

## 为什么是桌面 App 而不是网页

- **离线优先**：核心书单不需要网络就能读
- **性能**：Rust 原生解析 EPUB，比 JS 解压快一个数量级
- **文件访问**：直接读取 Calibre 书库的本地文件系统
- **长期主义**：网页服务需要运维（服务器成本、域名续费），违反"30 年不倒"的持久战约束
