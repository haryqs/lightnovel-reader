## 数据流

```
用户打开 epub
  ↓
Rust: 解压 ZIP → 解析 OPF → 返回 {metadata, toc, spine}
  ↓
前端: 渲染 TOC 侧栏，等待用户点击章节
  ↓
用户点击章节
  ↓
Rust: 提取对应 XHTML → HTML 清洗 → 返回干净的 HTML 字符串
  ↓
前端: paginator.ts 将 HTML 注入容器 → CSS Columns 分页
  ↓
用户翻页
  ↓
前端: 更新页码，通知 Rust 预加载下一章
```

## 章节预加载策略

当前章节 + 前后各 1 章常驻内存，其余按需加载。保证翻页零延迟。

## 标注数据模型

```
Annotation {
  id: string
  bookId: string          // 哪本书
  chapterHref: string      // 哪一章（epub spine href）
  cfi: string              // CFI 定位
  text: string             // 选中文本
  note: string             // 批注内容
  color: "yellow" | "red" | "blue" | "green"
  createdAt: number        // unix timestamp
}
```

标注持久化：本地 SQLite（标注数据库），与 Calibre 元数据 DB 分离。

## 标注导出格式（Obsidian 兼容）

```markdown
# 《书名》标注导出

## 第一章 标题

> 被标注的原文内容
> — 第 X 页

批注内容...

---
```

## Rust 依赖 (Cargo.toml)

```toml
zip = "2"                    # EPUB 就是 ZIP
quick-xml = "0.36"           # 解析 OPF/NCX/TOC
encoding_rs = "0.8"          # 编码检测（GB2312 等）
scraper = "0.20"             # HTML 清洗/选择器
rusqlite = { version = "0.31", features = ["bundled"] }  # Calibre + 标注 DB
```
