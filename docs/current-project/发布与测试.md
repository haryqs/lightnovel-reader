## 一、自动化冒烟（已就位，可重复跑）

前置工具：`tauri-driver` + `msedgedriver`。驱动版本须与当前 WebView2 Runtime 对齐，放在
`%LOCALAPPDATA%\lightnovel-reader-tools\msedgedriver\<版本>\`；插件 smoke 会优先选择已安装版本号最高的驱动，
但升级 WebView2 后仍须确认前三段版本一致。本机 2026-07-20 观察到 Runtime `150.0.4078.83`，旧 149 驱动已不可用。

```powershell
npm.cmd run tauri -- build --debug --no-bundle   # 先出 target\debug\reader.exe
npm.cmd run smoke:fixtures                        # 生成样本 EPUB
npm.cmd run smoke:tauri                           # UI 启动冒烟
npm.cmd run smoke:p0                              # 桥接全流程 + 重启恢复 + 解析缓存 + 图片
npm.cmd run smoke:p1                              # UI 交互：开书/翻页/划词高亮/真实 Calibre 读取
npm.cmd run smoke:remote-link                     # 在线远程条目 ↔ 本地书人工关联冒烟
npm.cmd run smoke:opds                            # OPDS 源添加/浏览/加入书架/书架获取并阅读冒烟
npm.cmd run smoke:plugin-repository-signature     # 临时密钥签名、篡改/错 key 拒绝、core/Tauri 验签回归
```

自动化冒烟已全绿（2026-06-13 起持续补充）。覆盖：导入/去重/元数据/封面、开书/取章、解析缓存落盘、
内联图片解码、进度与标注保存 + 第二会话恢复、书架卡片开书、翻页热区、鼠标划词建高亮 +
重开渲染、`list_calibre_books` 读真实 `F:\Calibre书库`。`smoke:remote-link` 额外覆盖在线 metadata
远程卡片与本地 EPUB 的人工关联、关联后进度/标注键不变、重复在线搜索不反弹无来源远程空壳。
`smoke:opds` 额外覆盖 OPDS URL 粘贴识别、添加源、浏览真实 OPDS feed、开放授权条目加入书架、
`acquisitionUrl` 持久化、从书架卡片获取入库并进入阅读态（书库层隐藏、状态栏可见、标题匹配）。
`smoke:plugin-repository-signature` 不需要 GUI 或公网：它生成临时 Ed25519 私钥与仓库 zip，调用正式签名脚本，
验证原始 zip 字节签名、单字节篡改和错误公钥拒绝，并执行 reading-core 与 Tauri 下载后校验回归。
它不替代真实 HTTPS 官方仓库窗口测试，且默认删除临时私钥和全部夹具。

## 三、打包

```powershell
npm.cmd run check:release-trust    # 必须先通过正式信任材料检查
npm.cmd run release:build          # 门禁通过后出 NSIS 安装器 + MSI（release）
```

`package:beta` 和 `installer:web` 也通过 npm pre-hook 自动执行同一门禁。门禁要求：

- `REQUIRE_OFFICIAL_PLUGIN_SIGNATURES = true`；
- `src-tauri/src/plugin_trust.rs` 至少有一枚合法、唯一 keyId 的 32 字节 Ed25519 公钥；
- `src-tauri/tauri.conf.json` 的 updater `pubkey` 非空；
- `bundle.createUpdaterArtifacts = true`，确保构建实际生成更新签名产物。

插件仓库签名公钥与 Tauri updater 公钥是不同用途的信任材料，必须分别生成和管理。首批公钥已于 2026-07-25
注入仓库，`check:release-trust` 已转绿；实际 `release:build` 仍必须从仓库外秘密管理注入 updater 私钥路径和密码，
不得把私钥、密码或临时明文写入仓库。

```powershell
$env:TAURI_SIGNING_PRIVATE_KEY_PATH = "<仓库外 updater 私钥路径>"
$env:TAURI_SIGNING_PRIVATE_KEY_PASSWORD = "<由秘密管理注入>"
npm.cmd run release:build
Remove-Item Env:\TAURI_SIGNING_PRIVATE_KEY_PATH
Remove-Item Env:\TAURI_SIGNING_PRIVATE_KEY_PASSWORD
```

产物：

```text
target\release\bundle\nsis\LightNovel Reader_<版本>_x64-setup.exe   # 自带卸载器
target\release\bundle\msi\LightNovel Reader_<版本>_x64_en-US.msi
```

NSIS 配置（`src-tauri/tauri.conf.json`）：当前用户安装（免管理员）、中英双语。
实测安装包约 7.4 MB（系统 WebView2，不打包渲染引擎）。

便携包（可选，下载即双击）：

```powershell
npm.cmd run package:beta      # → dist-beta\*.zip（reader.exe + 启动器 + README + 样本）
npm.cmd run installer:web     # → dist-installer\LightNovelReaderSetup.exe（下载+校验+安装 bootstrapper）
```

## 四、安装 / 卸载验证（已通过一次）

```powershell
Start-Process "...\LightNovel Reader_<版本>_x64-setup.exe" -ArgumentList "/S" -Wait   # 静默安装
# 安装到 %LOCALAPPDATA%\LightNovel Reader\，建开始菜单快捷方式 + uninstall.exe
Start-Process "$env:LOCALAPPDATA\LightNovel Reader\uninstall.exe" -ArgumentList "/S" -Wait  # 静默卸载
```

通过标准：安装后有桌面/开始菜单入口可启动；卸载后安装目录与快捷方式干净移除；
**卸载不删 `%APPDATA%` 下用户书库数据**（待真实数据目录下再确认一次）。

## 五、发版边界

- 便携包/Web 安装器不是自动更新器。真正的自动更新需签名、版本 manifest、回滚与更新源，
  属更高风险基础设施，不塞进 v0.3.1（见 `DECISIONS.md`）。
- 发布说明里标注：原生文件 / 文件夹选择对话框已于 2026-06-17 补验通过；已知限制据实写明。
