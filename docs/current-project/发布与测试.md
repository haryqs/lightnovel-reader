# 发布与测试（v0.3.1）

> 合并自原 `13_桌面冒烟清单` / `14_测试版打包与启动器` / `15_Web下载安装器`。
> 现已有自动化冒烟覆盖大部分 P0/P1；本文是发版前的命令与清单单一入口。

## 一、自动化冒烟（已就位，可重复跑）

前置工具（本机已装：`tauri-driver` + `msedgedriver`，版本须与 WebView2 Runtime 对齐，
当前 149.0.4022.62；放在 `%LOCALAPPDATA%\lightnovel-reader-tools\msedgedriver\<版本>\`）。

```powershell
npm.cmd run tauri -- build --debug --no-bundle   # 先出 target\debug\reader.exe
npm.cmd run smoke:fixtures                        # 生成样本 EPUB
npm.cmd run smoke:tauri                           # UI 启动冒烟
npm.cmd run smoke:p0                              # 桥接全流程 + 重启恢复 + 解析缓存 + 图片
npm.cmd run smoke:p1                              # UI 交互：开书/翻页/划词高亮/真实 Calibre 读取
```

三套已全绿（2026-06-13）。覆盖：导入/去重/元数据/封面、开书/取章、解析缓存落盘、
内联图片解码、进度与标注保存 + 第二会话恢复、书架卡片开书、翻页热区、鼠标划词建高亮 +
重开渲染、`list_calibre_books` 读真实 `F:\Calibre书库`。

## 二、仅剩的人工项（自动化覆盖不到）

- 系统**文件 / 文件夹选择对话框本身**（原生 OS UI）：点"打开/导入 EPUB/导入文件夹"，
  确认对话框能弹出、选中后正常导入。其 import 逻辑已由 smoke:p0 的路径版证过，低风险。

人工通过后即可打包发版。

## 三、打包

```powershell
npm.cmd run tauri -- build         # 出 NSIS 安装器 + MSI（release）
```

产物：

```text
target\release\bundle\nsis\LightNovel Reader_<版本>_x64-setup.exe   # 自带卸载器
target\release\bundle\msi\LightNovel Reader_<版本>_x64_en-US.msi
```

NSIS 配置（`src-tauri/tauri.conf.json`）：当前用户安装（免管理员）、中英双语。
实测安装包约 7.4 MB（系统 WebView2，不打包渲染引擎）。

便携包（可选，下载即双击）：

```powershell
npm.cmd run package:beta      # → dist-beta\*.zip（reader.exe + 启动器 + README + 样本）
npm.cmd run installer:web     # → dist-installer\LightNovelReaderSetup.exe（下载+校验+安装 bootstrapper）
```

## 四、安装 / 卸载验证（已通过一次）

```powershell
Start-Process "...\LightNovel Reader_<版本>_x64-setup.exe" -ArgumentList "/S" -Wait   # 静默安装
# 安装到 %LOCALAPPDATA%\LightNovel Reader\，建开始菜单快捷方式 + uninstall.exe
Start-Process "$env:LOCALAPPDATA\LightNovel Reader\uninstall.exe" -ArgumentList "/S" -Wait  # 静默卸载
```

通过标准：安装后有桌面/开始菜单入口可启动；卸载后安装目录与快捷方式干净移除；
**卸载不删 `%APPDATA%` 下用户书库数据**（待真实数据目录下再确认一次）。

## 五、发版边界

- 便携包/Web 安装器不是自动更新器。真正的自动更新需签名、版本 manifest、回滚与更新源，
  属更高风险基础设施，不塞进 v0.3.1（见 `DECISIONS.md`）。
- 发布说明里标注：仅剩原生文件选择对话框为人工验证项；已知限制据实写明。
