# 版权与合规边界

> 说明：本文不是法律意见，只是产品设计中的风险边界整理。正式发布前应请熟悉目标地区版权法的平台/开源/出版领域人士复核。

## 基本判断

**开源免费不等于不会侵犯版权。**

软件是否收费，与是否侵犯作品复制、传播、发行等权利不是同一个问题。

如果程序复制、下载、缓存、分发受版权保护的小说正文，即使项目免费开源，也可能构成风险。

## 高风险行为

以下行为不建议做：

- 内置盗版资源站。
- 官方维护盗版源规则库。
- 自动抓取商业站、连载站、付费站正文。
- 绕过登录、付费、会员、广告、DRM、地区限制。
- 将抓取到的正文缓存为本地可阅读文件。
- 分享用户导入的受版权保护文件。
- 以“插件”名义规避主项目合规边界。

## 低风险方向

以下方向相对稳妥：

- 本地文件阅读器。
- 用户自有文件管理。
- 公共版权作品。
- 开放授权作品。
- 明确允许下载/缓存的官方免费内容。
- 只聚合书目、版本、封面、作者、ISBN、出版社、官方链接等元数据。
- 跳转到官方购买、借阅、免费阅读页面。
- 接入 OPDS、图书馆、出版社、公共目录。

## 中间地带

以下内容需要逐项判断：

- 官方免费阅读页是否允许第三方客户端缓存。
- 作者个人网站是否允许复制全文。
- 翻译者发布的译文是否拥有原作授权。
- 用户自定义源是否可以被导出、分享、推荐。
- 插件是否只做元数据，还是实际抓取正文。

## 产品内的合规机制

建议在数据模型中显式记录：

```text
rights_status
risk_level
license_url
source_policy
can_download
can_cache
can_extract_fulltext
can_export
```

不要只靠 UI 文案提醒。能力限制应该进入程序逻辑。

## 来源评级

```text
L0  本地用户文件：用户自担来源，程序不上传、不分享
L1  公共版权：可下载、缓存、阅读
L2  开放授权：按许可证处理
L3  官方免费：优先跳转；缓存需明确许可
L4  官方购买/借阅：只跳转，不抓正文
L5  元数据源：只保存书目信息
L6  未知授权：只保存链接，不下载
L7  高风险/侵权：不收录、不推荐、不内置
```

阅读方式边界（2026-06-21）：

```text
浏览器打开       适用于官方入口、购买/借阅页、未知授权或官方免费但未确认可缓存的条目
内置阅读器       适用于本地文件、cached asset、公共版权、开放授权、明确允许获取的正文
外部本地阅读器   适用于本地文件或 cached asset；不应把远程受保护正文先抓取成本地文件
```

`official_free` 只说明用户可在官方页面免费阅读，不自动授予第三方客户端抓取、缓存或重新呈现正文的权利。

## 推荐红线

1. 官方发行版不内置侵权源。
2. 官方插件市场不接收正文抓取插件。
3. 不为绕过付费、登录、DRM 提供功能。
4. 不分发受版权保护的小说正文。
5. 不把“开源免费”当作免责理由。

## 可引用的公开资料

- 中国：《中华人民共和国著作权法》，可在国家法律法规数据库或中国政府网查询。
- 美国：U.S. Copyright Office 对 fair use 的说明指出，非营利/教育等因素只是判断因素之一，不自动等于合理使用。
- OPDS：开放出版物目录协议，可作为合法电子书目录接入的技术基础。
