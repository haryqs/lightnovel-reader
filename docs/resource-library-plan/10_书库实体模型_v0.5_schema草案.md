## 1. 目标与边界

把 v0.3 的 `books` 单表升级为轻小说作品图谱：**系列 / 卷 / 版本 / 资产 / 来源**。
这是产品潜力的容器——单表表达不了文库版/Web 版/译本、跨语种、多来源关系。

不变约束（迁移红线）：

- `annotations` 与 `reading_state` 以 **EPUB 内容哈希（bookId）** 为键，**本次迁移完全不动**。
  实体化只发生在书库层；标注/进度跟着内容走，天然不受影响。
- 迁移在 `migrations::run` 的 version 2 里完成，全程单事务、失败回滚（框架已保证）。
- 协议 1.0 冻结前定稿 `LibraryBook` DTO（见 §6）。

## 2. 实体分层（四层，合并 work）

```text
series   系列（无职转生 / SAO）
  └─ volume   卷/册（含外传、短篇集——用 volume.kind 区分，不单设 work 层）
       └─ edition  版本（日文文库版 / 繁中版 / Web 版 / 修订版；语种、出版社、译者、ISBN）
            └─ asset   可阅读实体（本地 EPUB/TXT；内容哈希 = 现 bookId）
source / source_record  来源与“某来源上的某记录”（Calibre/OPDS/Kavita/官方链接…）
```

合并 work 的理由（审阅结论）：绝大多数系列只有一个 work，五层对 UI/查询是纯负担。
外传/短篇/重制用 `volume.kind ∈ {main, side, anthology, remake}` 表达；真需要 work 层时再拆，
加层比删层容易。

## 3. 状态字段：两个正交维度

把文档 3 里混在一起的状态拆成两个正交字段（审阅结论）：

- `asset.availability ∈ {local, remote, missing, cached}` —— 资产在不在本地。
- `source_record.rights_status ∈ {public_domain, open_license, official_free,
  official_purchase, official_lending, user_owned, metadata_only, unknown, blocked}`
  —— 来源授权。

`metadata_only` / `external_link` 是“有 source_record 而无 asset”的自然结果，不设专门状态。
`blocked` 是来源属性，挂在 source/source_record 上，不挂 asset。

## 4. 建表 SQL（迁移 v2 草案）

```sql
-- ===== migration v2: books 单表 → 实体模型 =====

CREATE TABLE IF NOT EXISTS series (
  id          TEXT PRIMARY KEY,          -- slug 或 uuid
  title       TEXT NOT NULL,
  title_sort  TEXT,
  author      TEXT,
  description TEXT,
  cover_path  TEXT,                       -- 系列代表封面（可取首卷）
  created_at  INTEGER NOT NULL,
  updated_at  INTEGER NOT NULL
);

CREATE TABLE IF NOT EXISTS volume (
  id            TEXT PRIMARY KEY,
  series_id     TEXT REFERENCES series(id) ON DELETE SET NULL,
  kind          TEXT NOT NULL DEFAULT 'main',   -- main|side|anthology|remake
  volume_number REAL,                            -- 卷号（支持 2.5）
  title         TEXT NOT NULL,
  subtitle      TEXT,
  description   TEXT,
  created_at    INTEGER NOT NULL,
  updated_at    INTEGER NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_volume_series ON volume(series_id, volume_number);

CREATE TABLE IF NOT EXISTS edition (
  id            TEXT PRIMARY KEY,
  volume_id     TEXT REFERENCES volume(id) ON DELETE CASCADE,
  language      TEXT,
  publisher     TEXT,
  translator    TEXT,
  isbn          TEXT,
  edition_name  TEXT,                            -- “文库版”“Web版”“修订版”
  rights_status TEXT NOT NULL DEFAULT 'user_owned',
  created_at    INTEGER NOT NULL,
  updated_at    INTEGER NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_edition_volume ON edition(volume_id);

CREATE TABLE IF NOT EXISTS asset (
  id            TEXT PRIMARY KEY,          -- = 内容哈希（现 books.id / bookId），保持同源
  edition_id    TEXT REFERENCES edition(id) ON DELETE SET NULL,
  kind          TEXT NOT NULL DEFAULT 'epub',    -- epub|txt|html|pdf
  availability  TEXT NOT NULL DEFAULT 'local',   -- local|remote|missing|cached
  file_path     TEXT,                            -- objects/<id>.epub
  file_size     INTEGER,
  cover_path    TEXT,
  added_at      INTEGER NOT NULL,
  last_read_at  INTEGER
);
CREATE INDEX IF NOT EXISTS idx_asset_edition ON asset(edition_id);
CREATE INDEX IF NOT EXISTS idx_asset_lastread ON asset(last_read_at);

CREATE TABLE IF NOT EXISTS source (
  id             TEXT PRIMARY KEY,
  name           TEXT NOT NULL,
  kind           TEXT NOT NULL,            -- calibre|opds|kavita|komga|official_site|metadata|user_import
  base_url       TEXT,
  license_policy TEXT,
  risk_level     TEXT,
  enabled        INTEGER NOT NULL DEFAULT 1,
  created_at     INTEGER NOT NULL
);

CREATE TABLE IF NOT EXISTS source_record (
  id             TEXT PRIMARY KEY,
  source_id      TEXT REFERENCES source(id) ON DELETE CASCADE,
  entity_type    TEXT NOT NULL,            -- series|volume|edition|asset
  entity_id      TEXT NOT NULL,
  remote_url     TEXT,
  remote_id      TEXT,
  rights_status  TEXT NOT NULL DEFAULT 'unknown',
  availability   TEXT,                     -- 远端记录的可得性（与 asset.availability 区分）
  last_checked_at INTEGER
);
CREATE INDEX IF NOT EXISTS idx_source_record_entity ON source_record(entity_type, entity_id);

-- FTS 重建到 series + volume + edition（替代 books_fts）
CREATE VIRTUAL TABLE IF NOT EXISTS catalog_fts USING fts5(
  title, author, series_title,
  tokenize='trigram'
);
```

## 5. 回填策略（books → 实体）

每行 `books` 拆成一条链：series ← volume ← edition ← asset。当前单表里 series 是字符串、
series_index 是数字，正好对应：

```sql
-- 伪代码（迁移体内按行执行；id 用确定性派生，保证可重入/幂等）
-- series_id   = hash(series 名)；无 series 名则每本独立 series_id = 'solo-' || books.id
-- volume_id   = 'vol-'  || books.id
-- edition_id  = 'ed-'   || books.id
-- asset_id    = books.id                    -- 关键：asset.id 不变，标注/进度继续对得上
INSERT OR IGNORE INTO series(id, title, author, description, cover_path, created_at, updated_at)
  SELECT <series_id>, COALESCE(NULLIF(series,''), title), author, description, cover_path, added_at, added_at FROM books;
INSERT OR IGNORE INTO volume(id, series_id, kind, volume_number, title, description, created_at, updated_at)
  SELECT 'vol-'||id, <series_id>, 'main', series_index, title, description, added_at, added_at FROM books;
INSERT OR IGNORE INTO edition(id, volume_id, language, rights_status, created_at, updated_at)
  SELECT 'ed-'||id, 'vol-'||id, language, 'user_owned', added_at, added_at FROM books;
INSERT OR IGNORE INTO asset(id, edition_id, kind, availability, file_path, file_size, cover_path, added_at, last_read_at)
  SELECT id, 'ed-'||id, 'epub', 'local', file_path, file_size, cover_path, added_at, last_read_at FROM books;
```

要点：

- `asset.id = books.id`（内容哈希）→ annotations/reading_state 的 `book_id` 无需任何改动。
- 回填用 `INSERT OR IGNORE` + 确定性 id → 迁移可重入、不重复。
- `books` 表保留一个版本周期（v0.5 只读不写，作为回滚保险），v0.6 确认无碍后再 DROP。

    pub id: String,                 // = asset.id（内容哈希），不变

## 7. 读写路径迁移顺序（降低风险）

1. v0.5-a：建表 + 回填（本文 §4/§5），`import_epub*` 双写（写 books **和** 实体链）。
